# Changelog

All notable changes to Sayeed Speed X will be documented here.

## [1.0.0] - 2026-11-04

### Added
- Video playback speed control from 0x to 64x.
- Quick speed presets.
- Precision speed slider.
- Custom speed input.
- Increase and decrease speed controls.
- Enable/disable controller.
- Persistent user preferences using Chrome local storage.
- Support for Chrome Extension Manifest V3.

### UI
- Modern dark-themed interface.
- Speed Map with multiple presets.
- Precision Control section.
- Custom extension branding.
